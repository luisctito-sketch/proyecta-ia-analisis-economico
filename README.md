# PROYECTA-IA — CAPÍTULO V: FUNDAMENTOS ECONÓMICOS / ANÁLISIS ECONÓMICO

## Nombre recomendado del repositorio

`proyecta-ia-analisis-economico`

URL esperada:

`https://luisctito-sketch.github.io/proyecta-ia-analisis-economico/`

## Propósito

Ayudar al estudiante a identificar, clasificar, cuantificar, consolidar e interpretar los costos de un Proyecto de Grado tecnológico.

Este módulo NO realiza evaluación económica o financiera.

No calcula:
- VAN
- TIR
- B/C
- periodo de recuperación
- rentabilidad

## Categorías base

- Hardware / equipos.
- Software / servicios tecnológicos.
- Implementación / integración.
- Recursos humanos / mano de obra.
- Consolidación general.

Categorías opcionales:
- Actuadores / control físico.
- Infraestructura.
- Operación.
- Mantenimiento.
- Otros costos.
- Contingencia técnica.

## Reglas de las tablas

- Todos los montos en Bs.
- Dos decimales.
- Valores monetarios alineados a la derecha.
- Times New Roman 10 pt.
- Título encima, centrado y en negrilla.
- Fuente debajo.
- Cada tabla debe acompañarse de una interpretación económica.

## Funciones del chatbot

- Selección de categorías de costo.
- Clasificador automático de partidas.
- Registro de descripción, cantidad, unidad y costo unitario.
- Cálculo automático `Ci = Qi × Pi`.
- Subtotales por categoría.
- Diferenciación de desembolso directo, costo imputado y recurso disponible.
- Generación de tablas con formato institucional.
- Consolidación de costos.
- Contingencia opcional.
- Distribución porcentual por categoría.
- Costo del primer año cuando se incluyen operación y mantenimiento.
- Generación de guía de interpretación económica.
- Índice tentativo del Capítulo V.
- Revisor integral y prompt para ChatGPT.
- Descarga de partidas en CSV.
